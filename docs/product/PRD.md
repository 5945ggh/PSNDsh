# 个人面板 PRD

> 状态：首版持久化实现已完成并通过验收
>
> 版本：0.4
>
> 日期：2026-07-24

## 1. 产品定义

个人面板是一套部署在个人控制环境中的 Web 应用，用于统一管理每周计划、可嵌套条目、日程背景、真实专注时间和多尺度统计。它替代手工复制每周 Markdown 的工作流，同时保留树形表达、自由批注、历史回看和低约束记录。

系统未来可以向 Agent 提供受控结构化上下文，但首版不实现 Agent、LLM 或 MCP。

## 2. 产品原则

- 事实先于分类：可以先记录时间，稍后整理归属。
- 计划与事实并行：日程表达背景，专注表达实际投入，二者允许重叠。
- 统一而不抹平语义：方向、项目和待办共享条目模型，但完成行为不同。
- 低摩擦优先：常用操作不要求填写大量字段。
- 本地与隐私优先：默认只在用户控制的内网环境中处理数据。
- 可解释统计：直接投入、聚合投入和未关联投入必须可区分。

## 3. 用户、部署与时间口径

- 首版面向个人使用；`REGISTRATION_MODE` 可以控制是否允许多账号。
- 所有业务对象必须绑定用户，并在服务端校验归属。
- 支持桌面和手机浏览器；不开发原生客户端。
- 默认部署在单机或个人服务器上，使用持久化存储并提供备份恢复说明。
- 首版 `effectiveTimezone` 默认为 `Asia/Shanghai`；周从该时区下周一 `00:00` 开始。
- 绝对时间以 UTC 或带时区时间戳持久化；日期、星期、周界、月界和统计按 `effectiveTimezone` 解释。
- 产生业务数据后，首版不支持直接修改实例时区；变更必须通过后续迁移流程完成。

## 4. 核心领域语义

### 用户

- 注册只填写账号、密码和确认密码。
- 昵称和邮箱在设置页维护；邮箱可为空，不验证归属，不用于找回密码。
- 注册策略由 `REGISTRATION_MODE=first-user|open|closed` 控制，只通过环境变量修改。

### 条目

条目是统一核心对象，可表达长期方向、阶段项目、任务分组和具体待办。

- 条目形成树形结构，可有标题、描述、父条目、截止时间、排序、状态和完成模式。
- 完成模式包括 `ongoing`（持续型）与 `completable`（可完成型）。
- 所有条目都可以直接承接专注时间。
- 完成或归档父条目不得静默改变子条目。
- 常规删除以归档或软删除为主，不能破坏历史专注记录。

### 周计划

周计划表达“某一周主动纳入视野的条目”，不复制条目本身。

- 用户可将任意条目加入或移出本周。
- 新周首次访问时，上一周仍活跃、未完成、未归档且已纳入的条目幂等结转。
- 历史周保留当时的纳入关系，但展示条目的当前标题和状态。
- 周备注用于保留类似 Markdown 的周语境。

### 专注记录与片段

专注记录描述实际发生的一段活动时间。

- 同一用户同一时刻最多有一个活动计时器。
- 有效专注记录之间不得重叠。
- 专注可以无归属，也可以关联条目。
- 一次专注可拆分为多个片段；片段可以分别归属条目或未关联。
- 片段必须完整覆盖专注区间，不允许统计空洞。
- 拆分和重新归属不得改变专注总时长。

### 日程块

日程块表达课程、计划或其他时间背景。

- 支持手工创建和 ICS 单向导入。
- 日程可以与专注重叠，系统不得把重叠视为错误。
- ICS 采用“选择文件 -> 预览 -> 确认”两阶段流程。
- 重复事件在受限窗口内展开为具体日程；首版不持续同步，也不回写外部日历。

### 统计

统计必须可追溯到具体专注片段。

```text
aggregate(entry, range)
  = direct(entry, range)
  + sum(aggregate(child, range))
```

- 总时长等于全部片段时长之和，也等于各条目直接投入加未关联投入。
- 跨日、周、月边界的片段按实际重叠时长切分。
- 移动条目或重新归属片段后，历史统计按当前解释重新计算。
- 未关联时长必须单独可见。

## 5. 首版能力

- 登录、退出、会话恢复和注册策略。
- 设置页维护昵称和可选邮箱。
- 首页展示今日信息、当前专注、待办、截止项、投入摘要、本地季节名句和天气不可用状态。
- 条目树创建、编辑、状态流转、排序、移动、归档和本周纳入。
- 周计划查看、排序、移除、备注和自动结转。
- 实时专注、手动补录、编辑、拆分和重新归属。
- 周历同时展示日程与专注，支持手工日程和 ICS 导入批次管理。
- 日、周、月统计和条目树聚合。
- 当前账号结构化 JSON 导出。
- SQLite 数据库备份、校验和同版本空实例恢复。

## 6. 明确非目标

- 邮件发送、邮箱验证、找回密码。
- OAuth、企业登录、双因素认证。
- 多用户协作、共享计划、角色权限和管理员后台。
- Agent 主动读写、MCP、LLM 对话、自动摘要、智能分类和自动规划。
- 外部日历、教务系统的持续或双向同步。
- Markdown 历史批量导入和双向同步。
- 完整对象版本历史、审计回放和历史树快照。
- 原生 iOS、Android、macOS 或 Windows 客户端。
- 打卡连续天数、积分、排行榜和社交功能。

## 7. 延期项

| 能力 | 再进入范围的前提 |
|---|---|
| 真实天气 | 明确实例或用户级位置模型、设置入口、上游和缓存策略 |
| 名句预抓取 | 完成来源许可评估、抓取脚本、人工审核和内容包发布流程 |
| Agent/MCP | 定义数据最小化、读取范围、授权时效、操作审计和撤销机制 |
| 更强统计 | 明确周期对比、搜索、复盘和趋势分析的具体用例 |
