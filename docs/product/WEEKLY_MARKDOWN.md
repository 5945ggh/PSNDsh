# 本周清单 Markdown 约定

本周清单是每个 `WeekPlan` 保存的一段独立 Markdown 文本。它适合记录临时待办、自由批注、背景和复盘，不要求把每一项都创建为结构化条目。

## 结转规则

- 新周计划第一次创建时，原样复制上一周的清单内容。
- 上一周的计划不会因结转而改变；新周内容创建后独立编辑。
- 清单不会自动转换为结构化条目，也不会与条目树双向同步。

## 推荐语法

使用标准 Markdown 的稳定子集，方便后续进行语法分析：

```markdown
## ICS2

- [ ] OSTEP 阅读与梳理
  - [ ] IO & Files 36, 37, 38, 44
  - [ ] FS 39, 40, 41, 42

- [ ] Lab 4 - LockLab
  - [ ] 做

## 其他

- [x] 取白色T恤快递
- [ ] 构思服务器的使用
```

- 标题使用 `#`、`##` 或 `###`。
- 事项使用 `- [ ]` 或 `- [x]`。
- 子项使用缩进表达层级。
- 普通段落、引用、无序列表和行内 Markdown 可用于说明和批注。
- 删除线、非标准复选框和自定义标记暂时只作为显示文本，不承担结构化语义。

应用当前保留原文，不会因为保存而重排 Markdown。旧记录中的 `[]`、`[x]` 等自由写法可以继续保留；新增内容优先使用上面的标准写法。

## 与结构化条目的边界

如果内容需要累计专注时间、截止提醒、层级关系或跨周追踪，创建结构化条目；如果只是本周临时记录或自由清单，直接写入本周清单。
